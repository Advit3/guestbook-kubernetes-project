# Kubernetes Guestbook Final Project

This project is based on IBM's public Guestbook starter app for the Coursera lab. The upstream application and its Apache 2.0 license are included. See `SOURCE-ATTRIBUTION.md`.

## Project files

- `Dockerfile` builds the Go Guestbook app and copies its web assets into the image.
- `public/index.html` is version 1; `public/index-v2.html` is the updated page for the rollout.
- `deployment-v1.yml` describes the first Deployment. Set its image namespace before applying it.
- `deployment.yml` describes the updated Deployment with reduced CPU request/limit values for the CPU rollout. The course lab reuses the `v1` image tag when pushing the updated page.
- `submissions/answers-template.md` distinguishes file-based answers from outputs that must be captured from your own IBM lab session.

## Run the project in the IBM Skills Network lab

Use the lab terminal, where IBM Cloud CLI, Docker, and Kubernetes access are configured. Replace the namespace placeholder in the deployment YAML files with your `sn-labs-...` namespace.

```bash
export MY_NAMESPACE=sn-labs-$USERNAME
docker build . -t us.icr.io/$MY_NAMESPACE/guestbook:v1
docker push us.icr.io/$MY_NAMESPACE/guestbook:v1
ibmcloud cr images
kubectl apply -f deployment-v1.yml
kubectl autoscale deployment guestbook --cpu-percent=5 --min=1 --max=10
kubectl get hpa guestbook
```

Run the load-generator command from the course lab using your live application URL. Save the actual HPA output after replicas increase. To prepare v2, copy `public/index-v2.html` over `public/index.html`, rebuild and push the updated image using the lab's `v1` tag, then update the CPU values in `deployment.yml` for your namespace.

```bash
docker build . -t us.icr.io/$MY_NAMESPACE/guestbook:v1
docker push us.icr.io/$MY_NAMESPACE/guestbook:v1
kubectl apply -f deployment.yml
kubectl rollout history deployment/guestbook
kubectl rollout history deployment/guestbook --revision=2
kubectl rollout undo deployment/guestbook --to-revision=1
kubectl get rs
```

The registry digest, HPA scaling, deployment response, rollout revision details, and ReplicaSet counts are generated by the live IBM lab. Copy your actual terminal output into Coursera; don't use sample or guessed values.
